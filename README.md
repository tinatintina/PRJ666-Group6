## Project Description
Smart Spend is a web application designed to help students manage
their personal finances. Users can record income and expenses,
organize transactions into categories, create monthly budgets,
and view a basic financial dashboard.

## Technology Stack
- Frontend: React.js
- Backend: Node.js / Express.js
- Database: MySQL
- Version Control: Git / GitHub

## Core Features
- User registration
- User login
- Add income and expenses
- View transactions
- Transaction categories
- Monthly budget
- Basic dashboard

## Project Structure

frontend/ - React frontend application  
backend/ - Node.js and Express backend  
database/ - MySQL database scripts  
docs/ - Project documentation
